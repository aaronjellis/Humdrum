## What's new in v0.2.1

A small polish release after v0.2.0.

- **One version, clearly displayed.** The About box (App menu → About Humdrum) now shows a single version number instead of *"Version 0.2.0 (21.0)"* with two confusing numbers side by side. The sidebar in the main window also reads from the bundle automatically — previously it held a hand-typed "v0.1.0" left over from before the project was renamed to Humdrum.
- **Reliable auto-updates.** The Sparkle update pipeline that v0.2.0 introduced is now battle-tested end-to-end. **App menu → Check for Updates…** lands cleanly, including the case where some v0.2.0 installs hit a spurious "Update Error" on first install.
